# Landing Page - Dra. Mara Raquel

Landing page institucional para advocacia e consultoria jurídica da Dra. Mara Raquel.

## Estrutura

- `index.html`: marcação principal da página.
- `assets/css/styles.css`: estilos da landing page.
- `assets/js/main.js`: interações da navegação, formulário e botões.
- `assets/images/`: imagens usadas pelo site.
- `backup/`: cópia de segurança anterior.
- `int/`: capturas, checkpoints e anotações internas do projeto.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.
